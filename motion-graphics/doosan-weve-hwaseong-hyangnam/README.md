# 두산위브 에듀파크 화성향남 · 쇼츠 인트로/아웃트로 모션그래픽

유튜브 쇼츠(9:16, 1080×1920, 30fps)용 시작·끝 모션그래픽입니다.
브로셔(RS145)의 컬러(네이비·옐로·두산 We've 블루), 조감도·투시도, 핵심 수치를 그대로 반영했습니다.

## 1. AIDA 구조와 30초 쇼츠 배치

| 구간 | 파일 | 길이 | AIDA | 역할 |
|---|---|---|---|---|
| 시작 | `output/intro.mp4` | 3.5초 | **A**ttention → **I**nterest | 0.4초 만에 "84㎡ 3억대?!" 훅으로 스크롤을 멈추고, 두산 We've 브랜드 락업과 3대 팩트(2,110세대 · 향남역 5분 · 화성고 15분)로 흥미를 붙잡음 |
| 본편 | (팀장님 촬영분) | 약 20초 | Interest → **D**esire | 현장·모델하우스·설명 컷 |
| 끝 | `output/outro.mp4` | 6.0초 | **D**esire → **A**ction | "왜 지금일까요?" 3가지 이유(평당 900만원대 · 롯데캐슬 대비 53% · 향남역 5분) 카운트업 → "댓글에 '상담'" CTA → 구독·좋아요·알림 탭 애니메이션 |

## 2. 산출물

| 파일 | 용도 |
|---|---|
| `output/intro.mp4`, `output/outro.mp4` | 배경 포함 완성본 (H.264, 바로 편집 타임라인에 배치) |
| `output/intro_alpha.webm`, `output/outro_alpha.webm` | **투명 배경** 오버레이 (VP9 알파). 캡컷·프리미어(2023+)·다빈치 등에서 촬영 영상 위에 얹어 사용 |
| `output/*_alpha.mov` | 투명 배경 ProRes 4444. 용량(50~130MB)이 커서 저장소·채팅 전달에서 제외 — 필요 시 아래 `node render.mjs outro --alpha` 로 1분 내 재생성 |
| `intro.html`, `outro.html` | 편집 가능한 소스. 브라우저로 열면 바로 재생됨 |
| `assets/` | 브로셔에서 추출한 조감도·투시도 크롭, 배경 제거한 두산 We've 로고 |

## 3. 문구·수치 수정 방법

1. `intro.html` / `outro.html`을 텍스트 편집기로 열어 `<body>` 안의 한글 문구만 바꿉니다.
   - 아웃트로 전화번호: `<span class="tel">031-353-4230</span>` (브로셔 22쪽 확인서 기재 번호 기준 — **송출 전 반드시 확인**)
   - 카운트업 숫자: `outro.html` 스크립트의 `[[n1, 900, 0], [n2, 53, 0], [n3, 5, 0]]`
2. 브라우저(크롬)로 HTML을 열어 미리보기 (`?t=1.2`를 붙이면 해당 시점 정지, `?alpha=1`은 투명 버전).
3. 다시 렌더링:

```bash
cd motion-graphics/doosan-weve-hwaseong-hyangnam
npm install playwright          # 최초 1회 (크로미움 포함)
pip install imageio-ffmpeg      # ffmpeg 없을 때
node render.mjs all             # output/intro.mp4, output/outro.mp4
node render.mjs all --webm      # 투명 WebM
node render.mjs outro --alpha   # 투명 ProRes 4444 .mov
```

## 4. 사용한 브로셔 근거

- 두산건설 MOU 체결 확정 · 화성시 최초 두산건설 (2쪽)
- 2,110세대 · 21개 동 · 지하 3층~지상 27층 (3, 6쪽)
- 향남역(서해선 + 신안산선 계획) 차량 5분, 화성고 도보 15분 (3, 12쪽)
- 84㎡ 3억대 · 평당 900만원대(1차) · 리딩단지 대비 60~80% · 롯데캐슬 시그니처 대비 53% (14쪽)
- 지역주택조합 광고 고지 문구는 페이지 18~20의 절차·변경 가능성 안내를 근거로 추가
